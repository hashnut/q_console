# Claude API 크레딧 잔액 조회 수정

- 시작: 2026-10-30 (Asia/Seoul), HEAD `2f06128`.
- 증상: 앱이 잔액 $115.78(사용 $84.22)을 표시했으나 콘솔은 $142.36(사용 $57.64)였다.
- 원인 1: Opus 5.5·Sonnet 5.5 단가가 공식 가격표와 달랐다. 코드는 $5/$25, $3/$15에 캐시 읽기 0.1배였고, 공식 값은 $4/$20, $2/$10에 캐시 읽기 0.05배다. Haiku 5.5의 10만 토큰 구간 단가도 없었다.
- 원인 2: 잔액이 실제 값과 연결되지 않고 $200에서 로컬 추정액을 빼는 방식이었다. 이 PC 로그에 없는 사용분(약 $9)이 반영되지 않았다. 또 사용액을 달력 월 단위로 세서 11월 1일에 잔액이 $200으로 되돌아갈 수 있었다.
- 실제 잔액 조회 경로 조사: 개인 조직이라 Admin Cost API는 403이다(공식 문서에 "The Admin API is unavailable for individual accounts"). 선불 잔액 공개 API는 없다. Claude Code의 OAuth `prepaid/credits`는 Max 구독 조직 기준이라 0을 반환한다.

## 수정

- 콘솔 잔액 기준점: `--set-claude-credit <잔액> [시각]`과 트레이 메뉴 "Claude API 잔액 입력...". 잔액 = 기준점 − 기준점 이후 로컬 사용 추정. 월 경계를 쓰지 않는다.
- 단가표를 공식 가격표(2026-10-30 확인) 기준 `(입력, 출력, 캐시 읽기 배수)`로 바꾸고 Haiku 5.5 구간 단가를 추가했다.
- OpenCodex 행을 요청 완료 시각 기준으로 센다(스캔 캐시 이름 `opencodex-v2`).
- 툴팁에 출처(콘솔 기준점, Admin API, 로컬 추정)를 표시한다.
